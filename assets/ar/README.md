# Reper AR

Reperul Hiro, modelul de recunoaștere și calibrarea camerei provin din AR.js 3.4.8:
https://github.com/AR-js-org/AR.js/tree/3.4.8/data

AR.js: MIT. Licența ARToolKit este inclusă în ARTOOLKIT_LICENSE.txt.

Tipărește reperul pe hârtie mată, cu marginea albă păstrată. QR-ul aplicației deschide site-ul; acest reper stabilește poziția obiectului virtual.
